# Security policy

Sombra is an early research prototype. It has not received an independent security or cryptographic audit.

Do not treat the simulator as a production secure messenger.

Security reports should avoid public disclosure of an actively exploitable weakness until a fix is available.

## In scope

- routing state corruption
- unsafe bundle handling
- duplicate or expiry bypass
- future cryptographic integration flaws
- identity verification defects
- transport adapter boundary violations

## Out of scope

- compromised operating systems
- physical radio-layer attacks
- guaranteed resistance to interference
- anonymity against a global observer
- weaknesses in third-party hardware or firmware
