# Roadmap

## 0.1 — routing model

- transport-independent bundle core
- adaptive local routing policy
- deterministic degraded-network simulator
- cross-platform test matrix

## 0.2 — durable DTN queue

- bounded deduplication cache
- persistent delay-tolerant bundle store
- priority-aware bundle scheduler
- expiry pruning
- bounded retry backoff
- terminal queue workflow for opaque envelopes
- stronger randomized bundle identifiers

## Next

- authenticated envelope interface
- hardware-backed local identity adapter
- short-range transport adapter
- long-range low-bandwidth adapter
- measured link telemetry
- contact-window and node-churn simulation
- interoperability test vectors

Hybrid post-quantum key establishment remains a design target and will not be presented as implemented until the selected construction is stable, reviewed and covered by test vectors.
